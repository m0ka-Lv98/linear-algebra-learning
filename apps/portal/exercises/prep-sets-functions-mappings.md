## PREP-SFM-01：概念確認

$A=\{1,2,3\}$ について $2\in A$、$\{2\}\in A$、$\{2\}\subseteq A$、$\varnothing\subseteq A$ の真偽を判定せよ。

::: details ヒント1

:::

::: details ヒント2

:::

::: details 解法方針

::: details 完全解答

順に真、偽、真、真。$A$ の要素は数であり、集合 $\{2\}$ 自体は要素ではない。空集合は任意の集合の部分集合。

:::

:::

## PREP-SFM-03：手計算・導出

## PREP-SFM-08：実装・数値読解

## PREP-SFM-09：応用

`def affine(x: float) -> float: return 2*x+1` の型注釈と数学的な定義域・終域の違いを説明せよ。

:::

## PREP-SFM-10：応用

$f_1\colon\mathbb{R}^{10}\to\mathbb{R}^{20}$、$f_2\colon\mathbb{R}^{20}\to\mathbb{R}^{5}$、$f_3\colon\mathbb{R}^{8}\to\mathbb{R}^{2}$ とする。$f_2\circ f_1$ と $f_3\circ f_1$ の定義可否を判定せよ。

::: details ヒント1

まず対象・記号・shape・定義域のうち、この問題で必要なものを書き出す。

:::

::: details ヒント2

答えを出す前に、小さな展開・定義・手計算のどれかで根拠を確認する。

:::

::: details 解法方針

定義と成立条件を先に確認し、必要なら式を展開する。数値・コード問題では期待する型または値を先に予測してから計算する。
