## PREP-EL-09：応用

$\log(x^2)=2\log x$ の式で必要な定義域条件を説明せよ。

::: details 完全解答

## PREP-EL-10：応用

softmax計算で全scoreから同じ定数$c$を引いても確率が変わらない理由を式で説明せよ。

::: details ヒント1

まず対象・記号・shape・定義域のうち、この問題で必要なものを書き出す。

:::

::: details ヒント2

答えを出す前に、小さな展開・定義・手計算のどれかで根拠を確認する。

:::

::: details 解法方針

定義と成立条件を先に確認し、必要なら式を展開する。数値・コード問題では期待する型または値を先に予測してから計算する。

:::

::: details 完全解答

$e^{z_k-c}/\sum_j e^{z_j-c}=e^{-c}e^{z_k}/(e^{-c}\sum_j e^{z_j})=e^{z_k}/\sum_j e^{z_j}$。最大値を引けばoverflowを抑えやすい。

:::

::: details よくある誤答

指数の差し引きが各クラスの比を変えると考える。

:::
