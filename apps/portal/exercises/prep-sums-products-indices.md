## PREP-SPI-04：手計算・導出

$\sum_{i=1}^{n}a_i=\sum_{k=1}^{n}a_k$ が成立する理由を説明せよ。

::: details ヒント1

まず対象・記号・shape・定義域のうち、この問題で必要なものを書き出す。

:::

::: details ヒント2

答えを出す前に、小さな展開・定義・手計算のどれかで根拠を確認する。

:::

::: details 解法方針

定義と成立条件を先に確認し、必要なら式を展開する。数値・コード問題では期待する型または値を先に予測してから計算する。

:::

::: details 完全解答

$i$ と $k$ は総和記号内部のダミー添字で、同じ範囲の対応する項を列挙するため名称変更で値は変わらない。

:::

## PREP-SPI-07：誤りの診断

$y_i=\sum_{j=1}^{n}a_{ij}x_j$ の自由添字と総和添字を答え、それぞれの役割を説明せよ。

::: details ヒント1

まず対象・記号・shape・定義域のうち、この問題で必要なものを書き出す。

:::

::: details ヒント2

最小の反例または定義との不一致を一つ示す。

:::

::: details 解法方針

定義と成立条件を先に確認し、必要なら式を展開する。数値・コード問題では期待する型または値を先に予測してから計算する。

:::

::: details 完全解答

## PREP-SPI-10：応用

`A=np.array([[1,2,3],[4,5,6]])` について `np.sum(A,axis=0)` と `axis=1` の結果とshapeを答えよ。

::: details ヒント1

まず対象・記号・shape・定義域のうち、この問題で必要なものを書き出す。

:::

::: details ヒント2

コードを実行したつもりで、各行の入力・出力・shapeまたは値を順に追う。

:::

::: details 解法方針

定義と成立条件を先に確認し、必要なら式を展開する。数値・コード問題では期待する型または値を先に予測してから計算する。

:::

::: details 完全解答
