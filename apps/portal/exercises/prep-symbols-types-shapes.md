## PREP-STS-01：概念確認

$\mathbf{x}\in\mathbb{R}^4$、$\mathbf{A}\in\mathbb{R}^{3\times4}$ のとき、$\mathbf{A}\mathbf{x}$ の型と成分数を答えよ。

:::

::: details ヒント2

:::

::: details 解法方針

定義と成立条件を先に確認し、必要なら式を展開する。数値・コード問題では期待する型または値を先に予測してから計算する。

:::

::: details 完全解答

内側の次元4が一致するため積は定義でき、外側の3が残る。したがって $\mathbf{A}\mathbf{x}\in\mathbb{R}^3$ で成分数は3。

## PREP-STS-04：手計算・導出

式 $\mathbf{A}\mathbf{x}=b$ で $\mathbf{A}\in\mathbb{R}^{6\times2}$、$\mathbf{x}\in\mathbb{R}^2$、$b\in\mathbb{R}$ とした。型の観点から問題点を説明せよ。

## PREP-STS-05：手計算・導出

数学上のベクトル $\mathbf{x}\in\mathbb{R}^3$ をNumPyで `(3,)`、`(3,1)`、`(1,3)` と表したときの違いを説明せよ。

::: details ヒント1

まず対象・記号・shape・定義域のうち、この問題で必要なものを書き出す。

:::

::: details ヒント2

コードを実行したつもりで、各行の入力・出力・shapeまたは値を順に追う。

:::

::: details 解法方針

定義と成立条件を先に確認し、必要なら式を展開する。数値・コード問題では期待する型または値を先に予測してから計算する。

:::

::: details 完全解答

`(3,)` は1軸、`(3,1)` は3行1列、`(1,3)` は1行3列の2軸配列。数学上同じ成分を持っても行列積や転置の挙動が異なる。

:::

::: details よくある誤答

要素数が3なので完全に同一とみなす。

:::

## PREP-STS-06：誤りの診断

::: details ヒント2

:::

::: details 解法方針

::: details 完全解答

:::

## PREP-STS-07：誤りの診断

$\mathbf{A}\in\mathbb{R}^{2\times3}$ と $\mathbf{B}\in\mathbb{R}^{4\times2}$ について $\mathbf{A}\mathbf{B}$ と $\mathbf{B}\mathbf{A}$ の定義可否を判定せよ。

## PREP-STS-08：実装・数値読解

## PREP-STS-10：応用

ニューラルネットワーク層 $\mathbf{y}=\mathbf{W}\mathbf{x}+\mathbf{b}$ で $\mathbf{x}\in\mathbb{R}^{d}$、$\mathbf{y}\in\mathbb{R}^{h}$ とする。$\mathbf{W}$ と $\mathbf{b}$ のshapeを導け。
