# ベクトルと線形結合：教科書

## この章で理解すること

ベクトルは「向きと大きさを持つ矢印」だけでなく、複数の量を順序付きでまとめた対象である。線形結合は、既知のベクトルをスカラー倍して足し、新しいベクトルを作る最も基本的な操作である。

この章では、**直感 → 記号・shape → 定義 → なぜ成り立つか → 手計算 → 幾何 → アルゴリズム → 失敗条件 → 後続への接続**の順で理解する。

## まず直感

ベクトルは「向きと大きさを持つ矢印」だけでなく、複数の量を順序付きでまとめた対象である。線形結合は、既知のベクトルをスカラー倍して足し、新しいベクトルを作る最も基本的な操作である。

図を見るときは、軸・矢印・列空間・残差・楕円などの**各要素が数式のどの量に対応するか**を先に確認する。

## 記号・型・次元

- スカラーは小文字、ベクトルは $\mathbf{x},\mathbf{y}$、行列は $\mathbf{A},\mathbf{B}$ とする。
- $\mathbf{A}\in\mathbb{R}^{m\times n}$ なら、列数$n$が入力次元、行数$m$が出力次元である。
- 積・加算・逆・分解を行う前にshapeと成立条件を確認する。
- このTopicの代表式に含まれるすべての記号は、式の直前または直後で意味を説明する。

## 正式な定義

同じ空間 $\mathbb{R}^n$ のベクトル $\mathbf{v}_1,\ldots,\mathbf{v}_k$ とスカラー $c_1,\ldots,c_k$ に対して、$\mathbf{y}=\sum_{j=1}^k c_j\mathbf{v}_j$ を線形結合と呼ぶ。

代表式：

$$
\mathbf{y}=c_1\mathbf{v}_1+\cdots+c_k\mathbf{v}_k
$$

## 代表式の記号を定義する

- $\mathbf{v}_j\in\mathbb{R}^n$: 第$j$の入力ベクトル。
- $c_j\in\mathbb{R}$: 第$j$ベクトルに掛けるスカラー係数。
- $\mathbf{y}\in\mathbb{R}^n$: 線形結合で得る出力ベクトル。
- $k$: 組み合わせるベクトルの本数。

## なぜこの式になるのか

線形代数の多くは「どのベクトルを、どの係数で足せば目的のベクトルになるか」という問いに還元できる。行列とベクトルの積も、行列の列ベクトルの線形結合として読める。

ここでは最終式だけでなく、**どの条件から何が導かれたか**を追うことが重要である。

## 小さな手計算

$\mathbf{v}_1=(1,2)^\mathsf{T}$、$\mathbf{v}_2=(2,-1)^\mathsf{T}$ とする。$3\mathbf{v}_1-2\mathbf{v}_2=(-1,8)^\mathsf{T}$。係数 $(3,-2)$ が「2本の方向をどれだけ使うか」を指定している。

さらに確認問題：$\mathbf{a}=(2,-1,3)^\mathsf{T}$、$\mathbf{b}=(-1,4,0)^\mathsf{T}$ に対して $2\mathbf{a}+3\mathbf{b}$ を求めよ。

**解答**：$2\mathbf{a}=(4,-2,6)^\mathsf{T}$、$3\mathbf{b}=(-3,12,0)^\mathsf{T}$ なので、答えは $(1,10,6)^\mathsf{T}$。

小さい例で結果を先に予測し、その後で一般式へ戻る。

## 計算手順・アルゴリズム

成分数が一致していることを確認し、各ベクトルをスカラー倍してから成分ごとに加える。行列表現では列を並べた行列 $\mathbf{V}$ と係数ベクトル $\mathbf{c}$ を使い $\mathbf{V}\mathbf{c}$ と書ける。

理論上の定義と、有限精度で安全に計算するアルゴリズムは区別する。

## 成立条件と典型的な誤り

- ベクトルの「次元」とNumPy配列の `ndim` を同一視しない。
- 係数はベクトルではなくスカラーである。
- 異なる次元のベクトル同士は通常の線形結合として足せない。

特に、次の主張を自力で診断できるようにする。

> 「2本のベクトルを線形結合すれば必ず平面全体を作れる」

**診断**：誤り。同一直線上の2本なら生成できるのはその直線だけである。たとえば $(1,2)^T$ と $(2,4)^T$ は従属で、spanは1次元。

## 数値実装での検算

1. 入力の `shape` と `dtype` を確認する。
2. 2〜5次元の例で手計算した期待値を先に書く。
3. NumPy/SciPy等で計算する。
4. 残差、再構成誤差、直交性、rank、特異値など、このTopicに適した独立な量で検算する。
5. 逆行列の明示形成、normal equation、小pivot、小特異値など、数値誤差を増幅する実装を避ける。

## 後続Topicへの接続

後続のspan、列空間、基底、行列積、最小二乗法はすべて線形結合の言葉で統一できる。

Course 02の目的は各公式を孤立して覚えることではなく、**線形結合 → 空間 → 直交 → 最小二乗 → 固有構造 → SVD → 条件数**という一本の流れとして理解することにある。
