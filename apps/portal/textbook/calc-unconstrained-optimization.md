# 多変数の制約なし最適化

> Course 01｜微積分。目標は「公式を暗記して解ける」ではなく、**定義・成立条件・計算・判定・説明を一続きでできること**。試験答案では、結論だけでなく根拠となる条件を明示する。

## このTopicで答えられるようにする問い

多変数の損失関数を、勾配と曲率を使ってどう最小化するか。

## 到達目標

- 停留点を勾配ゼロから求められる
- Hessianで停留点を分類できる
- 凸性が大域最適性を強める理由を説明できる
- gradient descentの1ステップを計算できる

## 0. まず全体像

このTopicでは、式を見た瞬間に公式へ飛びつくのではなく、次の順で考える。

1. **対象は何か**：入力・出力・変数・次元を確認する。
2. **定義は何か**：公式が何を意味するかを言葉で説明する。
3. **成立条件は何か**：連続性、微分可能性、正定値性など必要な仮定を確認する。
4. **計算する**：途中式を省略しすぎず、規則を順番に適用する。
5. **検算する**：符号、単位、shape、極限、グラフの直感で矛盾がないかを見る。
6. **結論を書く**：局所／大域、必要／十分などを曖昧にしない。

## 1. 記号と前提

| 記号 | 意味 |
|---|---|
| $f(\mathbf x)$ | 最小化したい目的関数 |
| $\mathbf x^*$ | 最適解候補 |
| $\nabla f$ | 勾配 |
| $H_f$ | Hessian |
| $\eta>0$ | gradient descentのstep size（学習率） |
| $\mathbf x_k$ | $k$ 回目の反復点 |

新しい記号はこの表または本文中で意味を定義してから使う。

## 2. 中心概念を丁寧に理解する

### 1. 一階必要条件
微分可能な $f:\mathbb R^n\to\mathbb R$ が内点 $\mathbf x^*$ で局所極値を取るなら
$$\nabla f(\mathbf x^*)=\mathbf0.$$
ただし勾配0は候補条件であり、最小とは限らない。

### 2. 二階条件
停留点でHessianが正定値なら厳密な局所最小、負定値なら厳密な局所最大、不定なら鞍点。

### 3. 凸性
凸関数では任意の局所最小が大域最小になる。さらに微分可能な凸関数で $\nabla f(\mathbf x^*)=0$ なら $\mathbf x^*$ は大域最小。これは非凸問題との大きな違い。

### 4. Gradient descent
解析的に停留点が解けないとき、
$$\mathbf x_{k+1}=\mathbf x_k-\eta\nabla f(\mathbf x_k)$$
で反復する。負の勾配はその点での最急降下方向。ただし $\eta$ が大きすぎると飛び越えて発散し、小さすぎると収束が遅い。

### 5. 二次関数
$f(\mathbf x)=\tfrac12\mathbf x^TA\mathbf x-\mathbf b^T\mathbf x$、$A$ が対称正定値なら
$$\nabla f=A\mathbf x-\mathbf b.$$
最適条件は $A\mathbf x^*=\mathbf b$。線形方程式と最適化が同じ問題として現れる。

## 3. 計算・判定の標準手順

1. 勾配を計算する
2. $\nabla f=0$ を解いて停留点を得る
3. Hessianで分類する
4. 凸性が与えられていれば大域最適性を確認する
5. 反復法なら勾配を現在点で評価して更新する
6. step sizeと停止条件を確認する

## 4. 典型例を途中式つきで解く


**例1：** $f=(x-1)^2+2(y+2)^2$。勾配 $[2(x-1),4(y+2)]^T=0$ より $(1,-2)$。Hessian $\mathrm{diag}(2,4)$ は正定値なので大域最小。
**例2：鞍点。** $f=x^2-y^2$ は原点で勾配0だがHessian不定。最小ではない。
**例3：gradient descent。** $f=x^2+y^2$, $\mathbf x_0=[1,2]^T$, $\eta=0.1$。勾配は $[2,4]^T$、よって $\mathbf x_1=[0.8,1.6]^T$。

## 5. テストでよく起きる誤り

- 勾配0を大域最小と即断する
- Hessianの分類を省く
- gradient descentで勾配を加えてしまう
- 学習率の影響を無視する

## 6. 満点答案に近づける書き方

- 「局所」と「大域」を明確に書き分ける
- 凸性がある場合だけ結論を強める
- 反復法は各ステップでどの点の勾配かを添字で明示する

### 答案の共通チェック

- 使った定理・判定法の**条件**を満たしているか。
- 「候補」と「確定した結論」を区別しているか。
- 等号 $=$ と近似 $\approx$ を混同していないか。
- ベクトル・行列が出る場合、shapeが整合しているか。
- 問われた量に単位がある場合、単位まで書いたか。

## 7. 機械学習・数値計算への接続

これはMLの学習そのもの。実際にはSGD、Adamなどが使われるが、負の勾配方向へ目的関数を減らすという中心原理は同じ。
