# 数式・記号・型・次元：教科書

## この章で理解すること

この章では、数式に現れる量をスカラー、ベクトル、行列、多次元配列に分類し、各量の型とshapeを読み取る。さらに、行列積や機械学習のデータ配列を、演算前後のshapeから確認する。これは `origin: original` に相当する独自教材であり、MITの線形代数教材へ進む前提を補う。MIT教材の文章、問題、図の翻訳・転載は行わない。

## なぜ型とshapeを確認するのか

数式を読むとき、値だけを追うと「この足し算は定義できるか」「結果は何個の数か」を見失いやすい。型とshapeを先に書けば、計算の入口と出口が明確になる。例えば、2行3列の行列に4要素のベクトルを掛けることは、行列の列数とベクトルの要素数が合わないため定義できない。機械学習では、バッチ軸と特徴量軸を取り違えると、コードが動いても別の計算になることがある。

## スカラー

スカラーは1個の実数である。通常の小文字で

\[
a \in \mathbb{R}
\]

と書く。ここで \(a\) は実数、\(\mathbb{R}\) は実数全体の集合を表す。スカラーはベクトルや行列の各成分を表す値であり、行や列を持たない。Pythonの `float` はスカラー値として扱いやすい。一方、NumPyの0次元配列 `np.array(2.0)` は配列オブジェクトであり、値が1個でも `shape == ()` を持つ。この違いは、ライブラリの型検査では区別されることがある。

## ベクトル

本教材では数式上のベクトルを列ベクトルとして扱う。

\[
\mathbf{x}=
\begin{bmatrix}x_1\\x_2\\\vdots\\x_n\end{bmatrix}
\in\mathbb{R}^{n}
\]

\(x_i\) は第 \(i\) 成分、\(i\) は成分番号、\(n\) は要素数である。\(\mathbb{R}^{n}\) は実数を成分とする長さ \(n\) のベクトルの集合を意味する。例えば \(\mathbf{x}=[2,-1,3]^{\mathsf T}\) は \(\mathbb{R}^{3}\) のベクトルである。

数学上のベクトル空間の次元は、基底ベクトルの数である。これは配列の `shape` の値や `ndim` と同じ意味ではない。後述するNumPyの `(3,)` は、列ベクトルの値を保持できるが、行・列の向きを明示しない1次元配列である。

## 行列

行列は数を長方形に並べたもので、太字大文字で表す。

\[
\mathbf{A}\in\mathbb{R}^{m\times n}
\]

ここで \(m\) は行数、\(n\) は列数である。要素は \(a_{ij}\) と書き、\(i\) は行番号、\(j\) は列番号を表す。したがって \(a_{ij}\) は第 \(i\) 行第 \(j\) 列のスカラーであり、\(\mathbf{A}\) 全体とは区別する。

例えば

\[
\mathbf{A}=\begin{bmatrix}1&2&0\\0&-1&3\end{bmatrix}\in\mathbb{R}^{2\times3}
\]

は2行3列である。行列は数値表としても、データとしても、ベクトルを別のベクトルへ写す線形写像としても読める。どの意味で使っているかを文章や添字で確認する。

## 3階以上の配列

3階以上の配列は、カリグラフィック体の大文字で表す。

\[
\mathcal{X}\in\mathbb{R}^{b\times t\times d}
\]

ここで \(b\) はバッチサイズ、\(t\) は系列長、\(d\) は特徴量次元である。例えば \(32\times128\times768\) なら、32個の例それぞれに128個の位置があり、各位置に768個の特徴量があるという読み方ができる。機械学習ライブラリでは多次元配列を `tensor` と呼ぶことが多いが、ここでは主に多次元配列という意味で使う。数学上の抽象的なtensorの厳密な理論は扱わず、後続教材に送る。

## shape・axis・要素数・次元

| 用語 | 意味 |
| --- | --- |
| 型 | スカラー、ベクトル、行列、多次元配列など |
| shape | 各axisの要素数を並べたもの |
| axis | 配列を構成する方向 |
| 要素数 | shapeの各値の積 |
| 数学上の次元 | ベクトル空間の基底ベクトル数 |
| `ndim` | NumPy配列のaxis数 |

例えば `shape == (2, 3, 4)` なら、axis数は3、各axisの長さは2、3、4、要素数は \(2\times3\times4=24\) である。この情報だけから、数学上のベクトル空間の次元を一意には決められない。配列の軸に何が割り当てられたかは、データ仕様で確認する。

添字も数学とPythonで異なる。数学では原則として \(i,j=1,2,\ldots\) の1始まり、Pythonでは `A[i, j]` が0始まりである。数学の \(a_{13}\) はPythonでは `A[0, 2]` になる。

## 添字による要素の指定

\(\mathbf{A}\in\mathbb{R}^{m\times n}\) の要素 \(a_{ij}\) は、第 \(i\) 行第 \(j\) 列である。行列全体のshapeが \((m,n)\) であっても、要素一つ \(a_{ij}\) はスカラーである。添字の範囲が行数・列数を越えないことも、式を読むときの型検査の一部になる。

## 演算とshape

### 加算

同じ型・同じshapeの量を成分ごとに加える。例えば \(\mathbf{x},\mathbf{y}\in\mathbb{R}^{n}\) なら \(\mathbf{x}+\mathbf{y}\in\mathbb{R}^{n}\) である。行列でも同様に、対応する要素を足す。異なるshapeの加算を許すライブラリの規則は、数学の成分ごとの加算とは別に確認する。

### スカラー倍

スカラー \(a\) とベクトルや行列の積は、各成分を \(a\) 倍する。\(a\mathbf{x}\) は \(\mathbf{x}\) と同じshapeである。

### 内積

\[
\mathbf{x}^{\mathsf T}\mathbf{y}
\]

\(\mathbf{x},\mathbf{y}\in\mathbb{R}^{n}\) なら、転置した行ベクトルと列ベクトルの積はスカラーになる。実際には \(x_1y_1+\cdots+x_ny_n\) という同じ位置の積の和である。

### 行列・ベクトル積

\[
\mathbf{A}\mathbf{x}
\]

\(\mathbf{A}\in\mathbb{R}^{m\times n}\)、\(\mathbf{x}\in\mathbb{R}^{n}\) なら、結果は \(\mathbb{R}^{m}\) である。第 \(i\) 成分は、\(\mathbf{A}\) の第 \(i\) 行と \(\mathbf{x}\) の内積である。つまり、列数 \(n\) とベクトルの要素数が一致し、行数 \(m\) が結果に残る。

### 行列積

\[
\mathbf{A}\in\mathbb{R}^{m\times n},\quad
\mathbf{B}\in\mathbb{R}^{n\times p}
\quad\Longrightarrow\quad
\mathbf{A}\mathbf{B}\in\mathbb{R}^{m\times p}
\]

内側の次元が一致し、外側の次元が残る。ただしこれは語呂だけで暗記しない。結果の \((i,j)\) 成分は、\(\mathbf{A}\) の第 \(i\) 行と \(\mathbf{B}\) の第 \(j\) 列の内積である。したがって内側の添字を足し合わせる。

## データ行列

この教材では、観測を行、特徴量を列に並べる。

\[
\mathbf{X}\in\mathbb{R}^{N\times D}
\]

\(N\) は観測数、\(D\) は特徴量数である。100件の観測と20個の特徴量なら \(\mathbf{X}\in\mathbb{R}^{100\times20}\) である。重み \(\mathbf{w}\in\mathbb{R}^{20}\) に対して \(\mathbf{X}\mathbf{w}\in\mathbb{R}^{100}\) となり、観測ごとに1つの出力が得られる。ただしこの規約は普遍ではない。教材、論文、ライブラリごとに行と列の意味を確認する。

## 機械学習で現れるshape

\[
\mathcal{X}\in\mathbb{R}^{B\times T\times d_{\mathrm{in}}},\quad
\mathbf{W}\in\mathbb{R}^{d_{\mathrm{in}}\times d_{\mathrm{out}}}
\]

最後の特徴量axisへ線形変換を適用すると、

\[
\mathcal{Y}\in\mathbb{R}^{B\times T\times d_{\mathrm{out}}}
\]

となる。\(B\) はバッチサイズ、\(T\) は系列長、\(d_{\mathrm{in}}\) は入力特徴量数、\(d_{\mathrm{out}}\) は出力特徴量数である。バッチと系列のaxisは保持され、最後の768が256へ変わる、というように軸ごとの役割を説明する。実際のコードでは、ライブラリが想定するaxis順を必ず確認する。

## NumPyでの表現

```python
import numpy as np

x = np.array([2.0, -1.0, 3.0])
A = np.array([
    [1.0, 2.0, 0.0],
    [0.0, -1.0, 3.0],
])

y = A @ x

print(x.shape)  # (3,)
print(A.shape)  # (2, 3)
print(y.shape)  # (2,)
```

`x.shape == (3,)` は1次元配列、`A.shape == (2, 3)` は2次元配列、積の結果 `y.shape == (2,)` も1次元配列である。数学上の列ベクトルとNumPyの1次元配列は完全には同じ表現ではない。

列形状または行形状を明示する場合は次のようにする。

```python
x_column = x[:, None]  # (3, 1)
x_row = x[None, :]     # (1, 3)
```

`(3, 1)` は2次元の列形状、`(1, 3)` は2次元の行形状である。`(3,)` を自動的に行ベクトルまたは列ベクトルと断定してはいけない。broadcastingは便利だが、shapeを意図せず変えることがあるため後続Topicで扱い、この章では詳細化しない。

## よくある誤解

1. **ベクトルは必ず横または縦に表示される。** 数式では列ベクトルと約束しても、1次元配列は向きを持たない。表記の約束を確認する。
2. **shapeの値と数学上の次元は同じである。** `ndim`はaxis数であり、ベクトル空間の基底数とは別の概念である。
3. **要素数が同じなら行列積できる。** 必要なのは要素数ではなく、左の列数と右の行数の一致である。
4. **NumPyの`(n,)`は列ベクトルである。** `(n,)`は1次元配列で、行・列を明示しない。
5. **論文では常に行が観測、列が特徴量である。** 逆の規約もあり、軸の説明を読む必要がある。
6. **tensorは常に深い数学的定義を意味する。** 機械学習では多次元配列を指す用法が多い。文脈を区別する。

## まとめ

型は量の種類、shapeは配列の各axisの長さ、`ndim`はaxis数である。行列積は内側の次元を合わせ、結果には外側の次元が残る。NumPyの `(n,)` と数学上の列ベクトルは同一ではない。機械学習では、バッチ、系列、特徴量の各axisを定義してから演算を行う。
