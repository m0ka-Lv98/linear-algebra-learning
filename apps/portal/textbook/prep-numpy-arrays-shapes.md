# NumPy配列・shape・indexing：教科書

## この章で理解すること

NumPy配列の軸、shape、indexing、reshape、reduction、行列積を数学的対象と対応付ける。

- ndim、shape、size、dtypeを区別できる
- indexingとslicingの結果shapeを予測できる
- reshape、transpose、reductionでどの軸が変化するか説明できる
- 要素積と行列積、copyとviewの違いを説明できる

## 前提知識

Course 00で既に登場した記号は必要に応じて復習する。新しい記号・略語はこの章の初出時に意味を定義する。ベクトルは太字小文字、行列は太字大文字で表す。コード例では、数学上の意味とPython/NumPy上の表現を混同しない。

## この章の読み方

まず「対象は何か」「入力と出力は何か」「成立条件は何か」を確認する。式変形やコード実行の前に、型・shape・定義域・添字範囲を言葉で説明する。例題では答えだけでなく、なぜその操作が許されるかを一文で述べる。最後に反例または境界例を考え、理解が条件付きであることを確認する。

## NumPy配列は「値＋shape＋dtype」

NumPy配列を読むときは値だけでなく、`shape` と `dtype` を同時に確認する。`np.array([1,2,3])` と `np.array([[1,2,3]])` は同じ3値を含むが、前者はshape `(3,)`、後者は `(1,3)`。演算の意味やbroadcasting、行列積の結果が変わるため、要素数だけで同一視しない。
## ndim・shape・size

`ndim` は軸の数、`shape` は各軸の長さ、`size` は全要素数である。shape `(2,3,4)` なら `ndim=3`、`size=24`。数学のベクトル空間 $\mathbb{R}^{24}$ の「次元24」とNumPy配列の`ndim=3`は異なる概念である。
## dtype

`dtype` は各要素の表現形式を示す。整数配列と浮動小数点配列では除算、overflow、メモリ量などが変わる。機械学習では `float32` と `float64` の精度・速度・メモリのtrade-offがある。Course 00では、意図せぬ整数型や精度低下を防ぐため `A.dtype` を確認する習慣をつける。
## indexing

Python同様0始まりで、`A[i,j]` は第0軸のindex `i`、第1軸のindex `j` を指定する。数学の $a_{ij}$ が1始まりならコードでは `A[i-1,j-1]` に対応する。負indexは末尾から数えるため便利だが、数式との対応では明示的なindexを使う方が分かりやすい。
## slicingとshape

`A[:,1]` は全行から第2列を取り、2次元行列から1次元配列になる場合が多い。一方 `A[:,1:2]` は長さ1の第1軸を保持し2次元のまま。値が同じでもshapeが異なるので、後続の行列積で挙動が変わる。sliceはstopを含まない。
## reshape

`reshape` は要素数を保ったままshapeを変更する。ただし軸の意味を自動で理解するわけではない。例えば12値を `(3,4)` にできても、どの軸がsampleでどの軸がfeatureかはユーザーが管理する。データのsemantic axisを失わないことが重要である。
## transpose

2次元配列 `A.T` は行と列を交換する。高次元配列では単純な `.T` が全軸を逆順にするため、特定軸だけを並べ替えたい場合は `transpose` の軸指定を考える。1次元配列の `.T` はshapeを変えないので、列ベクトルが必要なら `x.reshape(-1,1)` などで2次元化する。
## 要素ごとの演算とbroadcasting

同shape配列の `A * B` は要素ごとの積である。NumPyはshapeが異なっても一定規則でbroadcastingできるが、意図しない軸へ拡張されると静かに誤った結果を生むことがある。Course 00ではbroadcastingの詳細規則より、「演算前後のshapeを予測して確認する」ことを重視する。
## sum・meanとaxis

`np.sum(A, axis=k)` は第$k$軸に沿ってreduceし、その軸を通常結果から消す。shape `(2,3)` に `axis=0` を指定すると `(3,)`、`axis=1` なら `(2,)`。`keepdims=True` なら長さ1の軸を残せる。高次元でも同じ原則で読める。
## 行列積

2次元配列では `A @ B` が行列積に対応する。`A.shape=(m,n)`、`B.shape=(n,p)` なら結果は `(m,p)`。`*` と `@` を混同しない。`np.dot` は入力次元により挙動が変わるため、線形代数の意図を明確にする初学段階では `@` を優先すると読みやすい。
## copyとview

NumPyのslicingやreshapeは元データとメモリを共有するviewを返す場合がある。viewを書き換えると元配列も変わることがあり、純粋な数学的「新しいベクトルを作った」感覚と異なる。独立コピーが必要なら `.copy()` を明示する。`np.shares_memory` などで確認できる場合もある。
## 機械学習での軸の意味

典型的なデータ行列は `(n_samples, n_features)`、画像batchは `(batch, height, width, channels)` など、各軸に意味がある。ライブラリによりchannel順序が異なることもあるため、shapeだけでなく軸名を文章や変数名で記録する。transposeやreshapeは数値を並べ替えるだけで、意味の整合性は保証しない。

## 詳細例で確認する

### 例題1

**問い**：`A=np.zeros((2,3,4))` の `ndim`、`shape`、`size` を答えよ。

**考え方**：定義・型・成立条件を先に確認し、答えを予測してから計算する。

**解答**：`ndim=3`、`shape=(2,3,4)`、`size=24`。

**誤りを避けるポイント**：数学の次元24を`ndim`と答える。

### 例題2

**問い**：`A=np.array([[1,2,3],[4,5,6]])` の `A[0,2]`、`A[:,1]`、`A[1,:]` を答えよ。

**考え方**：定義・型・成立条件を先に確認し、答えを予測してから計算する。

**解答**：`A[0,2]=3`、`A[:,1]=[2,5]`、`A[1,:]=[4,5,6]`。

**誤りを避けるポイント**：1始まりindexで読む。

### 例題3

**問い**：上の `A[:,1]` と `A[:,1:2]` のshapeを比較せよ。

**考え方**：定義・型・成立条件を先に確認し、答えを予測してから計算する。

**解答**：前者は `(2,)`、後者は `(2,1)`。sliceで範囲を残すと軸が維持される。

**誤りを避けるポイント**：値が同じなのでshapeも同じとする。

### 例題4

**問い**：`x=np.array([1,2,3])` の `x.T.shape` と `x.reshape(-1,1).shape` を答えよ。

**考え方**：定義・型・成立条件を先に確認し、答えを予測してから計算する。

**解答**：`x.T.shape==(3,)`、reshape後は `(3,1)`。

**誤りを避けるポイント**：`.T`だけで `(1,3)` になるとする。

### 例題5

**問い**：shape `(2,6)` の配列を `(3,4)` にreshapeできるか。理由も答えよ。

**考え方**：定義・型・成立条件を先に確認し、答えを予測してから計算する。

**解答**：総要素数が12で一致するので可能。ただし軸の意味が適切かは別問題。

**誤りを避けるポイント**：元shapeの各軸が割り切れないので不可とする。

### 例題6

**問い**：`A.shape=(2,3)` に対して `np.sum(A,axis=0)` と `axis=1` の結果shapeを答えよ。

**考え方**：定義・型・成立条件を先に確認し、答えを予測してから計算する。

**解答**：axis=0では第0軸が消え `(3,)`、axis=1では第1軸が消え `(2,)`。

**誤りを避けるポイント**：axis番号を残る軸番号と考える。


上の例題では、結果だけでなく、どの定義・条件を使ったかを言葉にする。自分の解答が数値だけの場合は、少なくとも一文の根拠を追加する。コード問題では実行結果だけでなく、実行前に期待する値またはshapeを書いて比較する。これにより、偶然正しい値が出た場合と、概念を理解して正しい値を予測できた場合を区別できる。

## 境界条件と反例の作り方

このTopicの公式や規則は、適用条件を外すと成立しない場合がある。境界値として0、1、空集合、長さ1の配列、定義域の端、shapeが一つだけ違う入力などを試す。さらに「よくある誤解」を否定する最小反例を自分で作る。反例が作れない場合は、用語の定義に戻り、何を変えると条件を壊せるかを考える。この作業は後続Courseで定理の仮定、数値アルゴリズムの前提、機械学習モデルの入力仕様を確認する際にもそのまま使える。

## 基本式・記法のチェックリスト

- `shape`=各軸の長さ

- `ndim`=軸数

- `A * B`=要素積

- `A @ B`=行列積

式を見たときは、各記号の意味、値の種類、添字範囲、必要な条件を説明できるか確認する。暗記した式を条件外で適用しない。

## よくある誤解

- **誤解**：`(3,)`、`(3,1)`、`(1,3)`は同じshapeである
- **誤解**：`axis=0`は常に「縦」とだけ覚えればよい
- **誤解**：`reshape`すれば軸の意味も自動的に正しく変換される
- **誤解**：sliceは常に独立したcopyを返す

誤解を見つけたら、単に「間違い」と覚えるのではなく、最小の反例を一つ作る。反例を自分で作れることは、定義を操作できているかを確認する有効な方法である。
