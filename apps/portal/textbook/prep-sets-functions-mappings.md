# 集合・関数・写像：教科書

## この章で理解すること

集合を使って対象の範囲を記述し、関数を入力と出力の対応として読む。定義域、終域、値域、像、逆像を区別し、合成、単射、全射、全単射、逆関数を判定する。これは `origin: original` に相当する日本語学習者向けの独自教材であり、MITその他の教材の文章・問題・図の翻訳や転載ではない。

## なぜ集合と関数を学ぶのか

数式には、どんな値を入力できるか、出力がどの集合に入るか、二つの操作を続けて適用できるかという前提がある。集合は対象の範囲を、関数は対応規則を表す。行列もベクトル空間から別の空間への写像として読め、機械学習モデルも入力集合から出力集合への写像として扱える。

## 集合と要素

集合は対象の集まりで、通常は要素の順序と重複を区別しない。

\[
A=\{1,2,3\},\qquad 2\in A,\qquad 4\notin A
\]

ここでAは集合、2は要素、\(\in\)は「要素である」を表す。\(\{1,2,3\}=\{3,2,1\}=\{1,1,2,3\}\) である。空集合を \(\varnothing\) と書き、要素を一つも持たない。

## 空集合

\(\varnothing\) と \(\{0\}\) は異なる。前者には要素がなく、後者には0という要素がある。空集合は任意の集合の部分集合である。

## 部分集合と等しい集合

集合Aのすべての要素が集合Bに含まれるとき、\(A\subseteq B\) と書く。要素と部分集合を区別するため、\(1\in\{1,2,3\}\) と \(\{1\}\subseteq\{1,2,3\}\) を比較する。二つの集合の等しさは両方向の包含と同値である。

\[
A=B\quad\Longleftrightarrow\quad A\subseteq B\text{ かつ }B\subseteq A
\]

## 集合の基本演算

\[
A=\{1,2,3\},\qquad B=\{2,3,4\}
\]

和集合は少なくとも一方に含まれる要素、共通部分は両方に含まれる要素、差集合は左だけに含まれる要素である。

\[
A\cup B=\{1,2,3,4\},\quad A\cap B=\{2,3\},\quad A\setminus B=\{1\}
\]

補集合は全体集合を先に指定して定義する。

## Cartesian積

\[
A\times B=\{(a,b)\mid a\in A,\ b\in B\}
\]

は順序対の集合である。\(A=\{1,2\}\)、\(B=\{p,q\}\) なら、\(A\times B=\{(1,p),(1,q),(2,p),(2,q)\}\) となる。順序対では \((1,p)\ne(p,1)\) である。

## 数の集合と区間

\[
\mathbb{N}=\{0,1,2,\ldots\},\quad \mathbb{Z}=\{\ldots,-1,0,1,\ldots\},\quad \mathbb{Q},\quad \mathbb{R}
\]

を自然数、整数、有理数、実数の集合とする。本教材では \(0\in\mathbb{N}\) とする。区間は \([a,b]=\{x\mid a\le x\le b\}\)、\((a,b)=\{x\mid a<x<b\}\) と書き、角括弧は端点を含み、丸括弧は含まない。半開区間 \([a,b)\)、\((a,b]\) も同様に読める。

## 関数と写像

\[
f\colon A\to B
\]

は、定義域Aの各要素に出力をちょうど一つ対応させる関数を表す。fは対応規則、Aは定義域、Bは終域である。異なる入力が同じ出力になることは許されるが、一つの入力に複数の出力を割り当ててはいけない。

## 定義域・終域・値域

\[
f\colon\mathbb{R}\to\mathbb{R},\qquad f(x)=x^2
\]

の定義域と終域はともに \(\mathbb{R}\) だが、実際の値域は負でない実数である。

\[
\operatorname{Im}(f)=[0,\infty)
\]

終域は出力先として指定した集合、値域は実際に得られる出力の集合であり、常に一致するとは限らない。

## 像と逆像

部分集合Sの像は \(f(S)=\{f(x)\mid x\in S\}\) である。終域の部分集合Tの逆像は

\[
f^{-1}(T)=\{x\in A\mid f(x)\in T\}
\]

である。ここでの \(f^{-1}(T)\) は集合の逆像であり、逆関数の存在を必要としない。例えば \(f(x)=x^2\) でも、\(T=[0,1]\) の逆像 \([-1,1]\) は定義できる。

## 恒等関数

集合A上の恒等関数は \(\operatorname{id}_A\colon A\to A\)、\(\operatorname{id}_A(x)=x\) である。\(f\circ\operatorname{id}_A=f\)、\(\operatorname{id}_B\circ f=f\) を満たす。

## 関数の合成

\[
f\colon A\to B,\qquad g\colon B\to C
\]

なら、\(g\circ f\colon A\to C\)、

\[
(g\circ f)(x)=g(f(x))
\]

を定義できる。右側の関数を先に適用する。\(f(x)=2x+1\)、\(g(x)=x^2\) なら、\((g\circ f)(x)=(2x+1)^2\)、\((f\circ g)(x)=2x^2+1\) であり、合成は一般に交換できない。

## 単射・全射・全単射

単射（injective）は \(f(x_1)=f(x_2)\Longrightarrow x_1=x_2\) を満たす関数である。全射（surjective）は終域のすべての要素が像になる関数で、\(\operatorname{Im}(f)=B\) と書ける。単射かつ全射が全単射（bijective）である。

## 逆関数

全単射 \(f\colon A\to B\) には \(f^{-1}\colon B\to A\) が存在し、\(f^{-1}(f(x))=x\)、\(f(f^{-1}(y))=y\) を満たす。\(f(x)=2x+3\) なら \(f^{-1}(y)=(y-3)/2\) である。

一方、\(f\colon\mathbb{R}\to\mathbb{R}\)、\(f(x)=x^2\) は \(f(1)=f(-1)\) なので単射でなく、全実数上では逆関数を持たない。定義域と終域を \([0,\infty)\) に制限すれば全単射となり、\(f^{-1}(y)=\sqrt y\) を持つ。

## 入力と出力の型

矢印は入力と出力の集合を記録する。式が計算できるだけでなく、入力が定義域に属し、出力が終域に属することが必要である。これは線形写像やニューラルネットワークの各層をつなぐときにも使う。

## Python関数との対応

```python
def affine(x: float) -> float:
    return 2.0 * x + 1.0
```

数学の \(f(x)=2x+1\) と対応するが、Pythonの型注釈は数学的な定義域・終域を完全には保証しない。合成は次のように書ける。

```python
def compose(g, f):
    return lambda x: g(f(x))
```

fの出力をgへ渡せるという契約を確認する必要がある。

## 機械学習モデルとの接続

モデルをパラメータ \(\boldsymbol{\theta}\) を持つ関数

\[
f_{\boldsymbol{\theta}}\colon\mathcal{X}\to\mathcal{Y}
\]

として表す。\(\mathcal{X}\) は入力空間、\(\mathcal{Y}\) は出力空間、\(\boldsymbol{\theta}\) は学習されるパラメータである。分類なら \(f_{\boldsymbol{\theta}}\colon\mathbb{R}^{d}\to\mathbb{R}^{K}\) と書け、dは特徴量数、Kはクラス数である。ネットワークは

\[
f_{\boldsymbol{\theta}}=f_L\circ f_{L-1}\circ\cdots\circ f_1
\]

という合成で、各層の出力型が次の層の入力型に適合しなければならない。

## よくある誤解

1. \(x\in A\) と \(\{x\}\subseteq A\) は同じではない。
2. 集合の要素の順序は通常区別しないが、順序対は区別する。
3. 終域と値域は常に同じではない。
4. 異なる入力が同じ出力になることは、一般の関数では許される。
5. \(g\circ f\) では右側のfを先に適用する。
6. すべての関数が逆関数を持つわけではない。
7. 逆像は逆関数と同じではない。
8. Pythonの型注釈だけでは数学的な定義域を保証しない。

## まとめ

集合は要素の集まりで、部分集合、和集合、共通部分、差集合、Cartesian積で関係を記述できる。関数 \(f\colon A\to B\) では、Aが定義域、Bが終域、実際の出力が値域である。合成は右側から適用し、単射かつ全射の全単射だけが逆関数を持つ。逆像は逆関数がなくても定義できる。機械学習モデルも入力空間から出力空間への関数と層の合成として読める。
