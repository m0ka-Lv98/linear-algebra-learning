# 一変数の最適化

> Course 01｜微積分。目標は「公式を暗記して解ける」ではなく、**定義・成立条件・計算・判定・説明を一続きでできること**。試験答案では、結論だけでなく根拠となる条件を明示する。

## このTopicで答えられるようにする問い

「傾きが0」を使って、最大・最小をどこまで確実に判定できるか。

## 到達目標

- 臨界点を求められる
- 一階・二階微分判定を使い分けられる
- 閉区間で絶対最大・絶対最小を判定できる
- 文章題を目的関数と制約へ変換できる

## 0. まず全体像

このTopicでは、式を見た瞬間に公式へ飛びつくのではなく、次の順で考える。

1. **対象は何か**：入力・出力・変数・次元を確認する。
2. **定義は何か**：公式が何を意味するかを言葉で説明する。
3. **成立条件は何か**：連続性、微分可能性、正定値性など必要な仮定を確認する。
4. **計算する**：途中式を省略しすぎず、規則を順番に適用する。
5. **検算する**：符号、単位、shape、極限、グラフの直感で矛盾がないかを見る。
6. **結論を書く**：局所／大域、必要／十分などを曖昧にしない。

## 1. 記号と前提

| 記号 | 意味 |
|---|---|
| $f(x)$ | 最大化・最小化したい目的関数 |
| $x^*$ | 最適解の候補 |
| $f^{\prime}(x)$ | 一階導関数 |
| $f^{\prime\prime}(x)$ | 二階導関数 |

新しい記号はこの表または本文中で意味を定義してから使う。

## 2. 中心概念を丁寧に理解する

### 1. 臨界点は「候補」であって答えではない
内点 $x^*$ で局所最大・局所最小をとり、かつ微分可能なら必要条件は $f^{\prime}(x^*)=0$。ただし $f^{\prime}(x)=0$ は十分条件ではない。たとえば $f(x)=x^3$ は $x=0$ で導関数0だが極値ではない。

### 2. 一階微分判定
臨界点の左右で $f^{\prime}$ の符号を見る。
- $+\to-$：増加から減少へ変わるので局所最大。
- $-\to+$：減少から増加へ変わるので局所最小。
- 符号が変わらない：極値ではない。

### 3. 二階微分判定
$f^{\prime}(x^*)=0$ かつ $f^{\prime\prime}(x^*)>0$ なら局所最小、$f^{\prime\prime}(x^*)<0$ なら局所最大。$f^{\prime\prime}(x^*)=0$ なら判定不能で、一階微分や別の方法へ戻る。

### 4. 閉区間の絶対極値
連続な $f$ を閉区間 $[a,b]$ で最適化する場合、内点の臨界点だけでなく**端点 $a,b$ も必ず比較する**。候補すべての関数値を計算し、最大・最小を選ぶ。

### 5. 文章題の型
1. 変数を定義する。
2. 最大・最小にしたい量を式にする。
3. 制約を使って1変数へ減らす。
4. 定義域を決める。
5. 微分して候補を求める。
6. 候補を比較し、単位付きで結論を書く。


## 3. 計算・判定の標準手順

1. 目的関数と定義域を書く
2. $f^{\prime}(x)=0$ または微分不能点を候補にする
3. 閉区間なら端点も候補に加える
4. 一階または二階微分で局所性を判定する
5. 候補の関数値を比較する
6. 文章題では元の問いに単位付きで答える

## 4. 典型例を途中式つきで解く


**例1：二次関数。** $f(x)=x^2-4x+7$。$f^{\prime}(x)=2x-4=0$ より $x=2$。$f^{\prime\prime}(x)=2>0$ なので局所最小。二次関数は上に凸なので絶対最小でもあり、最小値は $f(2)=3$。
**例2：閉区間。** $f(x)=x^3-3x$ を $[-2,2]$ で最大化・最小化する。$f^{\prime}=3(x^2-1)$ なので候補は $x=\pm1$ と端点 $\pm2$。値は $f(-2)=-2,f(-1)=2,f(1)=-2,f(2)=2$。最大値2、最小値-2。
**例3：面積最大。** 周長20の長方形で辺を $x,y$ とすると $2x+2y=20$、$y=10-x$。面積 $A=x(10-x)$、$0<x<10$。$A'=10-2x=0$ より $x=5$、よって正方形が最大。

## 5. テストでよく起きる誤り

- $f^{\prime}=0$ を見つけた瞬間に最小と断定する
- 閉区間で端点を忘れる
- $f^{\prime\prime}=0$ を「極値なし」と誤解する
- 文章題で定義域や単位を書かない

## 6. 満点答案に近づける書き方

- 必要条件と十分条件を区別する
- 候補一覧→判定→関数値比較の順に答案を書く
- 文章題では最適な変数だけでなく最大値・最小値も問われていないか確認する

### 答案の共通チェック

- 使った定理・判定法の**条件**を満たしているか。
- 「候補」と「確定した結論」を区別しているか。
- 等号 $=$ と近似 $\approx$ を混同していないか。
- ベクトル・行列が出る場合、shapeが整合しているか。
- 問われた量に単位がある場合、単位まで書いたか。

## 7. 機械学習・数値計算への接続

損失最小化は機械学習の中心問題。一変数で「停留点は候補」「曲率で局所形状を判定」という考え方を身につけると、多変数の勾配・Hessianへ自然につながる。
