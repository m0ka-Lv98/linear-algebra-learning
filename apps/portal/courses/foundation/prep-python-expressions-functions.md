# Pythonの式・変数・関数

## 今回解く問い

数式を小さなPythonプログラムへ移し、演算、制御構造、関数、型注釈、検算を安全に扱う。

## 概要

このTopicは、用語を暗記するだけでなく、定義→小さな例→誤りの診断→後続Courseへの接続という順で学ぶ。数式とPython/NumPyを対応付ける場合も、数学上の対象とコード上の表現を区別する。

## 学習目標

- Pythonの基本演算子と数学記号の対応を説明できる
- 条件分岐・反復・関数を使って小さな数値計算を記述できる
- 引数・戻り値・ローカル変数・型注釈の役割を説明できる
- 小さな手計算とコード結果を相互に検算できる
