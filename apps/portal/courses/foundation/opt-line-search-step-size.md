# line searchとstep size

## Course・Unit内での位置付け

Course 06「最適化」／Unit「最適化問題と凸性」／第605 Topic。

## 今回解く問い

line searchとstep sizeの定義、計算手順、成立条件を整理し、最適化の後続Topicへ接続する。どの条件で成立し、どの出力を得て、どの後続Topicへ接続するかを明確にする。

## 概要

line、search、step、sizeを、定義、直感、小さな例、計算、実装上の注意の順に整理する。

## 学習目標

- line、search、step、sizeの主要な定義と成立条件を説明できる。
- 小さな問題を手計算し、式・shape・数値結果を検証できる。
- line searchとstep sizeは、後続の数値計算・データ解析・機械学習で前提となる。
