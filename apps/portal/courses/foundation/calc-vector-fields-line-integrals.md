# ベクトル場と線積分

Course 01｜微積分

力場Fの中を曲線Cに沿って動くと、微小変位drに平行な力成分だけが仕事をする。内積 F·dr を経路全体で積分する。

## 到達目標

- 空間の各点にベクトルがあるとき、曲線に沿った仕事をどう足し上げるか。
- 中心式の各記号を定義してから計算できる。
- 成立条件と失敗条件を具体例で説明できる。
