# Monte Carlo・TD・Q-learning

Course 08｜機械学習

Monte Carloはepisode完了後の実returnをtargetにする。TDは1step先の現在推定値をbootstrapping targetにする。Q-learningはoff-policy TD control。

## 到達目標

- 遷移modelが未知でも、経験sampleだけから価値関数をどう学ぶか。
- 中心式の各記号を定義してから計算できる。
- 成立条件と失敗条件を具体例で説明できる。
