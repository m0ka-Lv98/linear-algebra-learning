# 数学基礎から現代機械学習までのカリキュラム設計

## 目的

MIT OpenCourseWareなどの大学講義の構成を参考にしつつ、日本語学習者が数学の意味、導出、数値計算、実装を段階的に結び付けられる独自教材を設計する。これはMITの公式教材でも翻訳サイトでもなく、学習順序と説明上の補助を日本語向けに再設計した非公式の学習基盤である。

最終的には、学習者が次をできることを目標とする。

- 大学初年級の数学を定義と直感の両面から説明する。
- WLSMを幾何学、統計、数値計算の観点から理解する。
- PCAと最適化、機械学習の基本手法を導出し実装する。
- backpropagationとattentionに現れる行列演算を追跡する。
- LoRA、Diffusion、state-space modelなどの論文を読む準備をする。
- 数学、アルゴリズム、数値安定性、実装上の判断を区別する。

## 教材の階層

```text
Course
└── Unit
    ├── Topic
    │   ├── テーマホーム
    │   ├── 概要スライド
    │   ├── 詳細教科書
    │   └── Topic演習
    ├── Recitation
    ├── Problem Set
    └── Unit Review

Course
├── Practice Exam
├── Exam
└── Project
```

Topicでは既存の4成果物（テーマホーム、概要スライド、詳細教科書、演習）を維持する。Recitation以下は、複数Topicを横断する教材を将来追加するための設計上の単位であり、今回の文書では実ファイルを追加しない。

## 3層の考え方

- **Core**：線形代数、微積分、確率統計、証明など、長期にわたり安定した数学。
- **Applied**：数値線形代数、最適化、統計的学習など、確立した応用理論と実装。
- **Frontier**：新しいモデルや論文を扱い、公開年、確認日、後続研究を記録して更新する領域。

Coreを先に固定し、Appliedでアルゴリズムと実験を学び、Frontierでは前提となる数式をCoreとAppliedへ戻って確認できるようにする。

## Topicの標準構成

### 概要スライド

問い、なぜ必要か、直感図、最小限の定義、小さな例、応用との接続を短く示し、最後に教科書と演習へのリンクを置く。

### 詳細教科書

次の順序を基本とする。

1. 学習目標
2. 前提知識
3. 記号と次元
4. 直感
5. 形式的定義
6. 幾何学的・統計的解釈
7. 手計算
8. 導出
9. アルゴリズム
10. Python実装
11. 数値計算上の注意
12. よくある誤解
13. 機械学習との接続
14. まとめ

### Topic演習

概念確認、手計算、導出・証明、実装、結果の診断を組み合わせる。解答は最終答、ヒント1、ヒント2、方針、定義、途中計算、完全解答、別解、典型的な誤答、Pythonによる確認、採点基準、関連教科書を必要に応じて含む。

## 日本語学習者への設計原則

- すべての記号を初出時に定義し、ベクトルや行列は最初に次元を示す。
- 数学、NumPy、PyTorchで異なる記法と、行列の各軸が表す意味を明示する。
- 証明、直感、実装上の確認を別の段落として扱う。
- 数式で示す方法と、数値計算で推奨する安定な方法を区別する。
- 英語の用語を併記し、論文や公式ドキュメントへ移るための語彙を残す。
