# 出典とライセンスの方針

## 基本方針

- 本リポジトリはMIT OpenCourseWareを参考にした非公式・非公認教材である。
- MITの名称やロゴを、提携や承認を示す形では使用しない。
- MIT教材の単純な翻訳を主目的にしない。説明、例題、演習は原則として独自に作成する。
- MIT教材を利用・翻案した場合は、個別リソースの出典と変更内容を示す。
- 個別リソースのライセンスを必ず確認し、MIT OCW全体の一般的なライセンスだけで判断しない。

## コンテンツ分類

```text
original
科目構成を参考にした独自教材

adapted
MITまたは他教材を翻案した教材

translated
原文を翻訳した教材
```

## 推奨メタデータ例

```yaml
origin: adapted
sources:
  - institution: MIT OpenCourseWare
    course: 18.06SC Linear Algebra
    resource: Projections onto Subspaces
    source_url: TODO
    license: CC BY-NC-SA 4.0
    accessed: YYYY-MM-DD
    changes: 日本語化、説明追加、例題変更
```

## 禁止事項

- 出典なしの翻訳
- MIT図版の無断転載
- MIT問題を独自問題として掲載すること
- ライセンス不明の画像や資料の利用
- MIT公認と誤認させる表現
- 原文を確認せず、MIT教材に含まれると断定すること

## 将来のライセンス案

以下は最終決定ではなく候補である。第三者素材には個別ライセンスを適用する。

```text
教材本文：CC BY-NC-SA 4.0候補
ソースコード：MIT LicenseまたはApache-2.0候補
第三者素材：個別ライセンス
```

既存リポジトリのライセンスは今回変更しない。
