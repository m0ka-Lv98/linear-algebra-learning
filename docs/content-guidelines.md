# 教材執筆規約

## テンプレート

新しいテーマは原則 `pnpm new:topic` で生成します。`templates/` の5ファイルはテーマ追加の骨組みを示す開発用テンプレートであり、公開サイトへそのまま掲載する対象ではありません。生成後、各成果物のTODOコメントを執筆内容へ置き換えます。

## スライド

- 概要と直感の理解を目的とする
- 原則として1スライド1概念
- 詳細な証明や長い式変形は教科書へ移す
- 最後に教科書と演習へのリンクを置く
- 教科書本文からスライドを自動生成しない

## 教科書

- 前提知識を明示する
- 直感、定義、具体例、導出、実装上の注意の順に説明する
- 各テーマの最後に演習へのリンクを置く
- スライドより詳しく、演習解答より一般的に説明する

## 演習

- 問題、ヒント、解法方針、完全解答を区別する
- 概念、手計算、導出、実装、診断、応用を将来扱える構造にする
- 解答は初期表示で隠す
- 問題と関連教科書ページを相互リンクする
